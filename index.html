📁 Firebase Storage Rules (แก้แยก)

                    
ไปที่ Firebase Console → Storage → Rules แล้วใส่:

                    

                        
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /tasks/{allPaths=**} {
      allow read: if request.auth != null;
      allow write: if request.auth != null;
      allow delete: if request.auth != null;
    }
  }
}

                        
                    

                    
                       🌐 เปิด Firebase Console → Storage Rules
                    
                


                

                    
📖 อธิบาย Rules นี้

                    
✅ tasks — อ่านได้ทุก anonymous user / เขียนได้เฉพาะคนที่ login Firebase

                    
✅ audit_logs — เขียนได้ทุก anonymous user / อ่านได้เฉพาะ Admin UID

                    
✅ config/holidays — อ่านได้ทุกคน / เขียนได้เฉพาะ Admin UID

                    
✅ config/users — อ่านได้ทุกคน / เขียนได้เฉพาะ Admin UID

                    
✅ config/adminUIDs — อ่านได้ทุก anonymous / เขียนได้เฉพาะ Admin UID

                    
✅ notes — อ่าน/เขียนได้ทุก anonymous user

                    
ℹ️ Admin UID คือ Firebase anonymous UID ของ device ที่ login รหัส 489961
